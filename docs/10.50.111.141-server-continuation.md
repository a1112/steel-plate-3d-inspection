## 7. 代码更新与交付注意事项

服务器更新前先执行：

```powershell
git status -sb
git fetch --prune origin
git log --oneline HEAD..origin/main
```

如果服务器工作区干净，只允许快进更新：

```powershell
git pull --ff-only origin main
```

如果服务器有本地修改，先保存 `git diff` 和配置副本并人工合并；不要使用 `git reset --hard`、不要覆盖现场 `capture.json`，也不要从仓库默认值反向覆盖服务器秘密、数据库或服务环境文件。

本轮界面改动尚未提交/推送，因此仅执行 `git pull` 还取不到这些修改。交付顺序应为：开发机验证并提交指定文件 → 推送 → 服务器 fetch/审核差异 → 按现有部署流程更新 → 重新执行本手册第 3、6 节。
