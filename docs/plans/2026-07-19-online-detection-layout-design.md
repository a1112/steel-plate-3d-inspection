# 在线检测页布局优化设计

## 目标

根据操作界面标注，减少重复的状态、统计与相机标签信息，释放主检测图与左侧钢管信息的可用空间，同时保留全部筛选、视图切换和相机展开交互。

## 结构调整

- 删除圆周展开图顶部的 `camera1` 至 `camera8` 标签轴，仅使用图内 `C1` 至 `C8` 标识。
- 移除生产记录产物提示和独立的实时跟随状态栏。将实时跟随状态、跟随模式，以及 2D / 3D / 点云视图切换整合到主图的横向 / 纵向工具行。
- 将缺陷类别和等级筛选移至缺陷检测列表上方。右侧统计面板改为“缺陷数量”，只显示类别按钮及各类别数量；删除钢管号统计行和“缺陷类别”子标题。
- 类别按钮使用响应式网格，而非固定两列；等级筛选在新位置使用具备足够背景对比度的状态样式。
- 左侧钢管信息改为无标题内容面板，增大字段区域高度。

## 交互与无障碍

- 现有筛选按钮的 `aria-pressed`、名称与回调维持不变。
- 2D / 3D / 点云和跟随模式继续保持单一可识别的工具栏分组。
- 移除的相机轴不承载交互，删除不会影响相机图像的点击、键盘导航或双击展开。

## 验证

- 单元测试验证相机标签轴、生产记录提示及旧统计标题不再呈现。
- 测试验证新筛选区保留类别和等级筛选按钮与数量。
- 运行客户端测试和构建；在本地浏览器确认页面没有重复工具栏，且布局在当前桌面视口正确显示。
