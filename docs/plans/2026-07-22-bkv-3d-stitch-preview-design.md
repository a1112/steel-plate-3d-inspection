# BKV 六相机 3D 无标定拼接预览设计

## 目标

使用已转换的 `bkv-depth-v1` NPZ，为旧系统钢管 `1893700` 生成六相机观察性拼接结果：一张纵向展开高度图和一个可旋转的近似圆柱三维表面。该结果用于确认数据连续性、相机覆盖和明显表面起伏，不作为尺寸、缺陷深度或空间标定证据。

## 已知输入

- 六个相机均有 21 帧，帧号可同步配对；
- 每帧宽度均为 1024 点；
- 六路单帧纵向行数分别为 682、646、632、541、692、677；
- 有效点比例约为 86.7%-94.2%；
- 各相机深度零点差异明显，且旧格式的物理单位尚未获得权威确认。

## 方案比较

1. **无标定展开和近似圆柱预览（采用）**：按帧号同步、纵向重采样、相机 1-6 顺序展开，并消除各相机整体零点偏差。可立即观察全部数据，但接缝和圆周角度只是近似值。
2. **直接复用当前生产八相机重建器**：能够输出完整生产网格，但 BKV 只有六路且缺少匹配标定，强行复用会制造错误的毫米坐标和验收结论。
3. **先反向解析旧 `.dat`/标定文件再做计量拼接**：最接近真实空间关系，但需要更多格式证据，不能作为“先看一下”的快速预览。

## 数据流

1. 读取 `CamImageSource1-6/1893700/3D/*.npz`，强制检查格式版本、字段、帧号和掩码。
2. 以同一帧号为同步单元，将六路纵向维度重采样到共同高度；不跨帧插值，避免破坏帧边界。
3. 每路只减去该相机所有有效点的稳健中位数，保留相机内部的原始相对起伏；无效点继续保持透明/缺失。
4. 将六路按 1→6 顺序沿圆周展开，接缝处画出明确边界，不伪装为已完成重叠配准。
5. 二维图使用全局稳健分位数统一着色；三维预览把六路等分映射到近似圆柱，深度残差只作为夸张显示量。

## 输出

- `tmp/legacy-bkv/stitch-preview/1893700/unwrapped-height.png`：六路展开高度图；
- `tmp/legacy-bkv/stitch-preview/1893700/stitch-summary.json`：输入、重采样、零点、有效率和可追溯哈希；
- 对话内可旋转三维预览：降采样圆柱网格，支持旋转和缩放，标出六个相机区域与接缝。

所有界面和元数据均标注 `uncalibrated / legacy-unknown`。任何无效输入、字段不匹配或帧集合不一致都应停止生成，而不是补零伪造。

## 验收

- 六路各 21 帧全部进入结果，无静默丢帧；
- 展开图能区分六个相机区域、帧方向和缺失点；
- 三维表面可旋转，且相机接缝清晰可见；
- 汇总文件记录 126 个 NPZ 输入及其 SHA-256；
- 输出不声称毫米单位、真实半径或已标定点云。
