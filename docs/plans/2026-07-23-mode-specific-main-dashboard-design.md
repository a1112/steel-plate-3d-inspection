# 相机直连与 BKV 主界面分化设计

## 目标

主界面必须由当前运行配置决定显示内容和数据来源。相机直连模式保留完整的
硬件、触发、采集和重建状态；BKV 模式使用已转换的标准离线仓库，不把相机、
触发网关或转换服务离线误报为主界面“服务异常”。

BKV 原离线回放页中的检测记录和检测图像世界迁入统一检测终端。旧回放页继续
作为兼容与运维入口，但不再承担主界面的业务数据源职责。

## 方案选择

采用“统一主界面 + 模式视图模型”。

`App` 根据公开运行配置和当前终端模式生成明确的视图模型，再传给顶部状态、
记录区域、主图区域和页脚。组件不自行猜测当前模式，也不以缺失的在线服务响应
推断 BKV 异常。

未采用的方案：

- 在各组件内继续零散判断 `terminalMode`：改动较小，但容易残留在线轮询和硬件
  状态。
- 拆成两套独立主界面：隔离更强，但会重复维护布局、缺陷筛选和图像交互。

## 运行模式与健康语义

### BKV 模式

主界面健康仅由以下条件决定：

1. Rust 服务可达；
2. 标准转换仓库可读；
3. 当前记录的检测图像世界元数据可用。

转换服务只负责导入和重试。已有标准数据可读时，转换服务离线只在后台管理页
提示，不影响主界面。相机 SDK、采集服务、触发网关、编码器、PLC 和 L2 均不参与
BKV 主界面健康判断。

BKV 顶部仅显示：

- BKV 模式；
- 离线数据路数；
- 批次；
- 数据就绪或数据异常。

不得实例化或显示相机状态、报级器网口、编码器、PLC、L2、采集服务、触发网关
和通用“服务异常”状态块。

### 相机直连模式

直连模式继续按检测服务、采集服务、触发网关、相机、网口、编码器、PLC、L2
判断运行状态，并显示八相机拓扑、采集管理和 3D 重建入口。

直连模式不得读取 BKV materials、BKV cursor 或 converted catalog。

## 数据流

### 检测记录

BKV 主界面首先读取 `/api/inspection-world/records`。标准记录 DTO 提供：

- 标准记录 ID 和旧序号；
- 钢管号；
- 钢种；
- 长度；
- 外径；
- 壁厚；
- 检测时间；
- 缺陷数量；
- 相机数量。

选中记录后，主界面以记录 ID 请求：

- `/api/inspection-world/meta`；
- `/api/inspection-world/defects`；
- `/api/inspection-world/tile`。

旧 `/api/bkv/materials` 只服务兼容回放，不再作为统一主界面的记录来源。

### 主图像

选中 BKV 记录后，主图立即进入稳定的“检测图像世界加载中”状态，不能先显示在线
相机平铺占位图。元数据就绪后直接显示相机本地瓦片画布。

切换记录时保留上一记录画布，直至新记录的元数据和首屏瓦片准备好，避免空白和
闪烁。后端缓存标准记录的世界元数据和头部对齐结果，避免当前约 4.5 秒的重复
计算。

主图严格使用标准仓库中的相机局部数据：

- BKV 配置只显示 C1-C6；
- 使用各相机真实宽度；
- 使用检测得到的头部偏移；
- 不生成均匀分格线；
- 不出现 C7/C8。

## 能力与入口

BKV 模式隐藏采集管理和 3D 重建入口。直接访问对应深链时返回检测终端并显示
能力提示。离线回放入口保持可用，但统一主界面的记录表和主图不依赖旧回放页。

直连模式恢复采集管理和 3D 重建入口，离线回放保持可见但禁用。

## 错误处理

- 标准仓库不可读：顶部显示“BKV 数据异常”，记录和主图区域显示具体原因。
- 单条记录元数据或瓦片失败：只标记该记录图像异常，不把整个系统标记为服务
  异常。
- 转换服务离线：只在后台管理显示。
- 在线服务异常：仅在直连模式按原健康规则显示。

## 验收

### BKV

- 顶部不存在相机、网口、控制和在线服务状态；存在 BKV 模式、6/6、批次和数据
  状态。
- 标准仓库返回 1893700-1893710 共 11 条记录。
- 主图只显示 C1-C6，真实宽度和头部偏移生效。
- 首次加载、切换记录、缩放和滚动不回退到在线占位图。
- 不请求在线 snapshot、采集、网络或触发接口。
- 采集管理和 3D 重建入口隐藏，禁用深链安全返回。

### 相机直连

- 顶部恢复八相机、网口、控制和服务健康状态。
- 采集管理和 3D 重建入口可用。
- 不请求 BKV 标准仓库或兼容回放接口。

### 验证方式

- Rust 单元和 HTTP 测试覆盖标准记录字段、元数据缓存与模式隔离。
- React 测试覆盖两种顶部、请求集合、记录切换和稳定加载状态。
- 使用当前 11 条真实数据做浏览器验收，检查网络请求、控制台、记录数量、相机
  标签、缩放和滚动。
