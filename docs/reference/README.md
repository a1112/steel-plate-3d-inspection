# Vendor reference documents

Large LVM3000/Capture manuals are intentionally not stored in this source
repository. Obtain the approved copies from the camera vendor or the project's
controlled internal document store.

Previously bundled document versions:

- Capture 6.5 software user manual V1.3.2
- LVM3000 series quick-start manual V1.4.1
- LVM3000 series hardware user manual V1.3.1
- LVM3 SDK user manual V4.0

Record the vendor URL, received checksum, license/distribution terms, and the
hardware/SDK version used for acceptance when adding a controlled reference.
